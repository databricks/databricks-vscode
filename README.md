# Databricks extension for VS Code

This repository contains the source code of the Databricks extension for VS Code. The extension is
in [packages/databricks-vscode](packages/databricks-vscode/README.md), and the types of its public
API are in [packages/databricks-vscode-types](packages/databricks-vscode-types). To contribute, see
[CONTRIBUTING.md](CONTRIBUTING.md).
